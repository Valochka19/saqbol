# Резюме проекта

**SaqBol — народная сеть датчиков мошенничества**
Трек: Cybersecurity / AI for Finance (фишинг-детектор, антифрод, защита платежей)
Тип: MVP / прототип с работающим демо
Автор: _[ФИО Владлены, курс, специальность]_ · Научный руководитель: _[ФИО]_

**Проблема.** За январь–ноябрь 2025 года в Казахстане зарегистрировано 26,3 тыс. интернет-мошенничеств
(+20,3 % за год, в 3,4 раза больше, чем в 2019-м), ущерб — 11,2 млрд тенге, и 96,7 % его пришлось на обычных
людей (данные Генпрокуратуры). Антифрод-центр Нацбанка за всё время работы заблокировал 2,8 млрд тенге:
банк узнаёт о мошеннике уже после перевода и только если пострадавший заявил. А заявляет, по опросам, лишь
каждый пятый (20,7 %). Номера и карты, с которых обманывают прямо сейчас, остаются в телефонах людей и
никуда не попадают.

**Решение.** Человек пересылает подозрительное сообщение, скриншот или голосовое в Telegram-бот, на сайт или
через «Поделиться» в Android-приложении. За 3–6 секунд он получает вердикт простыми словами: мошенники или
нет, какая это схема, по каким признакам видно и что делать. Одновременно из сообщения извлекаются телефоны,
карты, ссылки и аккаунты — они попадают в общую базу. Следующий человек, встретивший этот номер, увидит:
«на него уже жаловались N человек». Банк может сверять получателя перевода с базой до списания денег —
это показано на макете «Демо-банк».

**Как устроено.** Два слоя проверки: правила (работают без сети, ловят поддельные домены банков и типовые
формулировки) и языковая модель, которая понимает смысл на русском и казахском. На размеченном наборе из
90 сообщений, треть из которых намеренно трудные, правила дают точность 81 %, правила вместе с моделью —
98,9 % при полноте 100 %: ни одно мошенническое сообщение не пропущено. Тексты сообщений не хранятся,
в базу идут только реквизиты мошенников, а личность заявителя заменяется необратимым кодом.

**Что уже работает.** Бот @saqbolai_bot, сайт saqbol-ai-kz.web.app, Android-приложение с предупреждением
при входящем звонке с номера из базы. Кроме проверки — тренажёр из 40 случаев, «разговор с мошенником»
(нейросеть играет звонящего, в конце разбор ошибок), печатная памятка для родителей, страница мониторинга
для антифрод-службы. Одна проверка стоит около 1 тенге, расходы на модель за всю разработку — меньше
одного цента.

**Новизна.** Существующие инструменты в Казахстане работают либо с уже случившимися переводами
(Антифрод-центр), либо с блокировкой звонков у оператора. SaqBol собирает сигнал раньше всех — в момент,
когда человек только сомневается, — и превращает каждую проверку в защиту для следующих.

**Ожидаемый эффект.** Для людей — бесплатная проверка за секунды. Для банков — ранний список реквизитов
мошенников, которого нет в официальных базах, и готовый инструмент обучения клиентов. Уровень готовности —
TRL 4 (прототип проверен в лабораторных условиях), следующий шаг — пилот с одним банком.
