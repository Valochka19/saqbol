## К 22.09 включительно — письмо на rahimabk@mail.ru

Положение требует три вещи: заявку, резюме проекта и материалы.

- [ ] **Данные Владлены** — ФИО, курс, специальность, кафедра, научный руководитель, телефон, почта ← нужно от Романа
- [ ] Заявка по форме Приложения 1 (заполняется из данных выше) + название темы выступления
- [ ] Резюме проекта — 1 страница
- [ ] One-pager: проблема, целевая аудитория, решение, ценность, новизна
- [ ] Pitch-deck, 10–12 слайдов: рынок/контекст, архитектура, данные, метрики, план внедрения, риски, бюджет
- [ ] Техническое приложение: методика, датасет, ссылка на репозиторий, метрики, план доработки (TRL)
- [ ] Демо: ссылка на сайт и бота (видео — к защите)
- [ ] Цифры про мошенничество в Казахстане из открытых источников (Нацбанк, МВД, АРРФР) — для слайда «контекст» и раздела «эффект»
- [ ] Репозиторий сделать публичным перед отправкой письма

## К 25.09 — защита: 5–7 минут + 10 минут вопросов

- [ ] Бот на сервере, а не на ПК Романа (иначе сайт не отвечает, когда ПК спит)
- [ ] Шпаргалка для Владлены: сценарий выступления по минутам, что нажимать в демо, ответы на вопросы
      (в т. ч. «какая юридическая сила у сертификата», «как раскрутите», «куда уходят данные», «выдержит ли нагрузку»)
- [ ] Видео-демо до 5 минут — запасной вариант, если в аудитории не будет интернета
- [ ] Репетиция с Владленой: один прогон вслух с таймером
- [ ] Перед защитой: убрать тестовые записи из базы (сертификат «Тест Тестов», заявка «Тестовый банк») — только с ОК Романа
- [ ] ID чата Романа в боте (/myid), чтобы заявки с «Тарифов» приходили в Telegram — для живого демо
