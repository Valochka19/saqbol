# SaqBol

Народная сеть датчиков мошенничества для Казахстана. «Сақ бол» — «будь осторожен».

Человек проверяет подозрительное сообщение — система объясняет, мошенники ли это, а номера телефонов,
карты и сайты из мошеннических сообщений попадают в общую базу. Следующий, кому придёт тот же номер,
увидит «на него уже жаловались», а банк получает дроп-счёт в день рассылки, а не после заявления пострадавшего.

- Сайт: https://saqbol-ai-kz.web.app
- Telegram-бот: [@saqbolai_bot](https://t.me/saqbolai_bot)
- Android-приложение: `SaqBol-0.2.apk` (Android 10+), ссылка на сборку — в техническом приложении

Проект для республиканского конкурса студенческих проектов Ассоциации банков РК «Твори, дерзай, побеждай», 2026.

## Устройство

```
saqbol-bot/    Python: Telegram-бот и вся серверная логика
  saqbol/rules.py       слой 1 — правила, работает без сети
  saqbol/llm.py         слой 2 — языковая модель (Gemini или Claude, переключается в .env)
  saqbol/analyzer.py    склейка слоёв в один вердикт
  saqbol/indicators.py  извлечение телефонов, карт, доменов, аккаунтов
  saqbol/store.py       общая база в Firestore, риск-скоринг, сводка для сайта
  saqbol/webqueue.py    очередь запросов с сайта
  saqbol/simulator.py   «Разговор с мошенником»
  saqbol/chat_features.py проверка номера, тренажёр, разговор и памятка внутри Telegram
  eval/                 датасет из 90 сообщений и скрипт метрик
saqbol-site/   Next.js + TypeScript + Tailwind, статический экспорт на Firebase Hosting
saqbol-android/ Kotlin + Jetpack Compose; определитель звонков, «Поделиться», сканер QR
docs/          цифры по Казахстану с источниками, материалы заявки, тестовые QR-коды
```

Отдельного бэкенда у сайта и приложения нет: они кладут запрос в коллекцию Firestore, бот обрабатывает его и пишет
ответ под тем же id. Правила Firestore открывают сайту только готовую сводку (агрегаты и замаскированные
номера) и очередь запросов. Тексты сообщений не хранятся.

## Метрики

90 размеченных сообщений, 30 из них намеренно трудные.

| Режим | Accuracy | Precision | Recall | F1 | Трудные кейсы |
|---|---|---|---|---|---|
| Только правила | 0.811 | 0.818 | 0.800 | 0.809 | 18 из 30 |
| Правила + модель (gemini-3.8-flash) | 0.989 | 0.978 | 1.000 | 0.989 | 29 из 30 |

Подробности и воспроизведение — в [saqbol-bot/README.md](saqbol-bot/README.md).

## Запуск

Бот:

```
cd saqbol-bot
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env        # TELEGRAM_BOT_TOKEN и GEMINI_API_KEY
# firebase-key.json — ключ сервис-аккаунта Firebase, положить рядом с bot.py
.venv\Scripts\python bot.py
```

Сайт:

```
cd saqbol-site
npm install
npm run dev                   # http://localhost:3000
npx next build && npx firebase-tools deploy --only hosting
```

Приложение: открыть `saqbol-android` в Android Studio или `./gradlew assembleDebug` (JDK 21).

## Безопасность и данные

- Тексты сообщений, скриншоты и голосовые не хранятся: запрос удаляется сразу после ответа.
- В общую базу попадают только реквизиты мошенников; заявитель заменяется необратимым кодом.
- Наружу (сайт, приложение) уходят только агрегаты и замаскированные номера.
- Ключи бота и базы в репозитории нет. Веб-ключ Firebase в коде — публичный, доступ ограничен правилами
  `saqbol-site/firestore.rules`.
