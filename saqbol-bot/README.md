# SaqBol AI

Telegram-бот, который проверяет SMS, сообщения из мессенджеров и ссылки на мошенничество
и объясняет вердикт на русском или казахском. «Сақ бол» — «будь осторожен».

## Как устроен

```
сообщение -> [1. правила] -> [2. LLM] -> вердикт + признаки + совет
```

1. **Правила** (`saqbol/rules.py`) — поддельные домены под Kaspi/Halyk/eGov, сокращённые ссылки,
   просьбы назвать код из SMS, «безопасный счёт», AnyDesk, срочность и т.д. Работает офлайн.
2. **LLM** (`saqbol/llm.py`) — Gemini Flash (или Claude, переключается в .env) получает текст и результат правил, возвращает структурированный
   вердикт: тип схемы, признаки, совет. Если LLM недоступна, бот отвечает на одних правилах.
3. **Склейка** (`saqbol/analyzer.py`) — итоговое решение. Поддельный домен банка не может стать
   «безопасным», даже если модель ошиблась.

Тексты сообщений не сохраняются, в `stats.jsonl` пишется только обезличенная статистика.

## Запуск

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env      # вписать TELEGRAM_BOT_TOKEN и GEMINI_API_KEY
.venv\Scripts\python bot.py
```

Проверка без Telegram: `.venv\Scripts\python check.py "текст сообщения"`

## Метрики

Датасет: `eval/dataset.jsonl`, 90 сообщений (45 мошеннических, 45 обычных; русский, казахский, смешанный, транслит).
30 из них — намеренно трудные: скам без тревожных слов и ссылок, домены-опечатки, и наоборот — настоящие
уведомления о долгах, реклама займов, курьер с кодом выдачи.
Примеры составлены по типовым схемам, распространённым в Казахстане.

```
.venv\Scripts\python eval\run_eval.py          # только правила
.venv\Scripts\python eval\run_eval.py --llm    # правила + LLM
```

| Режим | Accuracy | Precision | Recall | F1 |
|---|---|---|---|---|
| Только правила | 0.811 | 0.818 | 0.800 | 0.809 |
| Правила + LLM (gemini-3.8-flash) | 0.989 | 0.978 | 1.000 | 0.989 |

На трудных случаях: правила — 18 из 30, правила + LLM — 29 из 30.

Ошибки слоя правил — это случаи, где нужен смысл, а не ключевые слова: просьба вернуть долг
за пиццу похожа на «переведи денег», а угон Telegram через «проголосуй за племянницу» не содержит
ни одного тревожного слова. Их закрывает LLM-слой.
